# Attendance Checker — Version 1

## Overview

Cross-platform (Windows / macOS) desktop application for event attendance checking using Thai national ID smart cards (PC/SC reader). Staff insert a card into a USB smart card reader; the app reads all fields via APDU, matches the ID against a pre-imported attendee list, and records the check-in.

## Key Features

- **Smart card reading** — Thai national ID card via PC/SC / pcsclite, full APDU sequence
- **Manual entry** — staff can type the 13-digit Thai ID if the card reader is unavailable
- **Walk-in support** — attendees not on the pre-registered list can still check in (staff confirmation required)
- **CSV / Excel import** — import attendee list before the event; supports `.csv`, `.xlsx`, `.xls`
- **Attendance summary** — real-time stat cards, progress bar, searchable check-in table, CSV export
- **Bilingual UI** — Thai / English, switchable at runtime
- **No external runtime** — ships as a self-contained installer (NSIS on Windows, DMG on macOS)

## Tech Stack

| Layer | Technology |
|---|---|
| Shell | Electron 33 |
| Renderer | React 18 + TypeScript + Vite |
| Styling | Tailwind CSS v4 |
| Icons | Lucide React |
| i18n | i18next + react-i18next |
| Database | better-sqlite3 (SQLite, bundled native module) |
| Smart card | pcsclite (bundled native module) |
| Card encoding | iconv-lite (TIS-620) |
| CSV parse/export | PapaParse |
| Excel import | ExcelJS |
| Packaging | electron-builder (NSIS / DMG) |

## Getting Started (development)

```bash
npm install
npm run dev          # Starts Vite + Electron concurrently
```

## Building for distribution

```bash
npm run build        # Compile renderer (Vite) + main (tsc)
npm run dist         # Package with electron-builder → release/
```

> **Native modules** (`better-sqlite3`, `pcsclite`) must be rebuilt against the Electron Node version after `npm install`:
> ```bash
> npx @electron/rebuild
> ```
